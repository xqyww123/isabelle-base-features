# isabelle-base-features

Fixes to Isabelle's own sources, as feature packages for
[isabelle-patch-control](https://github.com/xqyww123/isabelle_patch_control). Each package is a
directory whose `README.md` explains its fix.

The README of isabelle-patch-control says how to install feature packages. How to work on a feature
and release it: the SKILL
[`isabelle-patch-feature`](https://github.com/xqyww123/isabelle_patch_control/blob/main/.claude/skills/isabelle-patch-feature/SKILL.md).
